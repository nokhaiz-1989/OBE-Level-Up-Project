# OBE Level-Up — Initial Prototype

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## What this version contains

- 5 teams
- Team joining
- Five OBE levels
- Team progression
- Individual team pyramids
- Presenter dashboard
- Live progress within the same Streamlit session
- Demo controls

## Important

This first version is a prototype of the game mechanics.

For the actual workshop, the next version should add a shared online database (Supabase or Firebase), so five separate devices can submit simultaneously while your presenter screen receives their progress in real time.

The five final activity types should then be:

1. Sort / drag evidence — Identify
2. Case study — Define
3. Build / sequence — Design
4. Find and repair mismatch — Align
5. AI rescue / teacher refinement — Evaluate & Refine
